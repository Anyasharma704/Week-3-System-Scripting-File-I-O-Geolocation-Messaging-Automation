# WhatsApp Message Scheduler
Install: `python -m pip install pywhatkit`
Run: `python whatsapp_messenger.py`
Schedules one message to one phone number through WhatsApp Web. Use international phone format and a future time later today.
**Responsible use:** Only message recipients who agreed to receive messages. No bulk messaging or spam. WhatsApp Web must be signed in; delivery is not guaranteed and browser automation may change.
